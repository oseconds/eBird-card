== Project Overview

eBird-readme-card automatically generates a GitHub-ready SVG card from a user's public eBird activity.

== Goals

* Scrape recent public checklist IDs.
* Combine scraped IDs with official eBird API data.
* Render a dark-themed SVG using Jinja2 templates.
* Update automatically through GitHub Actions.
* Eventually publish as a reusable GitHub Action.

[source,yaml]
----
- uses: oseconds/eBird-readme-card@v1
  with:
    ebird_user_id: ${{ secrets.EBIRD_USER_ID }}
    ebird_api_key: ${{ secrets.EBIRD_API_KEY }}
----

== Why Jinja2?

Instead of building SVG with string concatenation, the project uses Jinja2 templates so the SVG layout stays readable while Python only supplies data.
