## Why?

There are many GitHub profile widgets.

There are many birding platforms.

But there isn't a simple way to display your recent eBird activity directly inside a GitHub README.

**eBird-readme-card fills that gap.**

It combines information from your public eBird profile with official eBird API data to generate a beautiful SVG card that updates automatically through GitHub Actions.

Inspired by:

- github-readme-stats
- waka-readme-stats
- spotify-github-profile

---

## Features

- Beautiful GitHub-ready SVG cards
- Automatic updates
- Public profile integration
- Official eBird API support
- Jinja2 template system
- Lightweight
- Fast rendering
- Theme support *(planned)*
- Reusable GitHub Action *(planned)*
